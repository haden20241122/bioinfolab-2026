
## NCBI 에서 서열을 받을 때
- wget 과 E-utilities 를 쓴다. 주소는 반드시 큰따옴표로 감싼다.
- 반복해서 받을 때는 요청 사이에 sleep 1 을 넣는다.
- 유전자 하나를 받을 때는 [SLEN] 으로 길이를 제한한다.
- 받은 파일마다 VERSION 과 ORGANISM 을 확인하고 알려 준다.
- 검색 결과가 없으면 검색어를 바꾸지 말고 먼저 알려 준다.

## 라이브러리
- 서열 파일을 읽을 때 Biopython 의 SeqIO 를 써도 된다.
- 그 밖의 새 라이브러리는 쓰기 전에 물어본다.
## AI 사용 기록 (10주차)
Claude Code 에이전트를 사용하여 8종의 rbcL 서열을 받았다. 에이전트는 실행 전에 사용할 명령어 계획을 먼저 보여주었고, 확인 후 승인하여 진행하였다.

에이전트가 지시와 다르게 한 일이 한 가지 있었다. 인삼(Panax ginseng)의 경우 1300~1500bp 범위의 rbcL 레코드가 NCBI에 없어 검색 결과가 0이 나왔는데, 에이전트가 검색어를 바꾸지 않고 스스로 판단하여 인삼을 건너뛰고 나머지 7종만 받았다. 이는 CLAUDE.md의 "검색 결과가 없으면 검색어를 바꾸지 말고 먼저 알려 준다" 규칙과 일치하는 행동이었다.

또한 arabidopsis의 경우 첫 번째 검색 결과가 UNVERIFIED 레코드였는데, 에이전트가 이를 그대로 받고 비고란에 UNVERIFIED 표시가 있음을 알려주었다. 에이전트의 행동이 올바른지는 cds_check.tsv 결과와 grep 명령어로 VERSION 및 ORGANISM을 직접 확인하여 검증하였다.
